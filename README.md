# Km Líquido

App para motoristas de aplicativo que dividem um carro: mostra quanto sobra de verdade das corridas (dinheiro no bolso), com uso particular, custos do dono e acerto de combustível.

- Abra pelo celular: https://meu-app-loja.github.io/km-liquido/
- Dados e login: Firebase (Firestore + login por e-mail e senha).
- `firestore.rules`: regras de segurança do banco (colar no console do Firebase).
